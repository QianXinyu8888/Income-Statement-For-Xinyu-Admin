# 自用产品操作区设计

## 目标

让自用产品列表的操作区具备清晰的主次层级，并减少现有两个描边小按钮造成的零散感。

## 方案

采用已确认的 C 方案“主次按钮”：

- “标记在售”作为无边框、低强调的次操作，保留现有的状态变更行为和辅助功能名称。
- “确认售出”作为蓝色实心主按钮，保留售出确认窗口和现有辅助功能名称。
- 在在售页中只显示蓝色实心的“确认售出”按钮。
- 桌面列表和手机卡片复用同一套操作组件与样式。

## 交互与可访问性

- 操作仍为两个独立按钮，支持键盘 Tab、Enter 和现有焦点环。
- 保存中仍禁用对应按钮；不改变状态更新、售出确认或错误提示逻辑。

## 验收

- 自用页中“标记在售”不再有边框，且不与“确认售出”争夺视觉重心。
- 主、次按钮文字完整展示，不使用省略号截断；空间不足时保持文字可读。
- “确认售出”按钮为 macOS 蓝色实心按钮，文本和图标清晰可辨。
- 在售页的售出按钮保持可访问名称“确认出售 {物品名}”。
