# 移除月度利润图当前月高亮设计

## 背景

月度利润图当前会通过 `isCurrentMonth` 标记将当前月份横轴标签显示为更深颜色和更粗字重。用户希望当前月与其他月份完全一致，不再通过横轴样式突出当前月。

## 设计

- 从月度利润图数据结构中删除 `isCurrentMonth` 字段。
- 删除横轴标签渲染中的 `is-current` 类名和 `current-month-tick` 测试标记。
- 删除当前月份横轴标签的专属 CSS，使所有月份统一使用普通灰色和相同字重。
- 同步更新共享月份数据测试与图表组件测试。

## 保持不变

- 当前月仍排在图表最左侧，其后按月份倒序排列。
- 无交易月份仍连续展示，利润显示为 `0`。
- 月份格式仍为 `YYYY.MM`。
- 利润数值、盈亏颜色、提示框、分析月份选择器及数据请求不变。
- 概览页使用独立轻量图表且原本没有当前月高亮，保持现状；分析页移除高亮后，两处月份标签视觉一致。

## 验收标准

1. 当前月与其他月份横轴标签的颜色和字重完全一致。
2. DOM 中不再生成当前月专属类名或测试标记。
3. 月份排序、补零、日期格式和利润展示相关测试继续通过。
4. 桌面端与手机端不出现新的截断或横向溢出。
