# 手机端侧边栏与经营视图重设计

## 目标

重做已登录后的手机端界面，使其保留电脑端所有现有业务功能、路由、数据字段和 API 行为，同时采用覆盖式左侧导航而不是固定底部标签栏。手机端的默认入口仍是“交易明细”；“经营概览”和“利润分析”保持一跳可达，并强调经营数据的浏览与下钻。

本设计只重组手机端的视觉层级与交互容器，不新增业务功能、指标、筛选条件或数据来源。

## 应用壳与导航

- 桌面侧栏和顶部工具栏维持现状。
- 在最大宽度 680px 的手机视口中，隐藏桌面侧栏、顶部工具栏和既有底部导航。
- 手机页面顶部使用紧凑栏，包含左侧菜单按钮和当前页面标题；交易页保留新增交易操作。
- 点击菜单打开从左侧滑入的覆盖式抽屉，遮罩不改变底层页面状态；点击遮罩、菜单关闭按钮、Escape 和横向关闭手势（若现有实现不增加手势支持则可省略）关闭抽屉。
- 抽屉按桌面端顺序提供：交易明细、经营概览、利润分析、自用中、在售中、设置；底部提供主题切换、语言选择和退出登录。
- 抽屉中的导航继续使用原有路由。激活项使用浅色背景、文字色和简短左侧指示，不能只依赖颜色。

## 交易明细

- 保持默认路由 `/transactions`；首屏依然以搜索、筛选、新增交易和交易列表为主体。
- 标题下方显示紧凑的本月利润摘要，可跳转至经营概览；此摘要不替换交易列表，也不加入未经 API 支持的新指标。
- 手机列表继续显示商品名称、状态、购入/售出日期、成本和利润等现有字段。列表行保证 44px 以上触控区域，点击仍进入现有编辑流程。
- 搜索始终可见；状态、日期、排序及重置条件收纳到从底部滑出的筛选面板。现有的导出、列设置、分页、多选、批量状态和批量删除功能保持可访问：空间不足的操作收进清晰的溢出菜单，而不删除能力。
- 新增或编辑交易使用近全屏移动表单，顶部显示返回/关闭与标题，字段单列排列；能保持可读性时日期与金额字段可两列排列。保存区固定于底部，考虑安全区和软键盘。
- 已选中记录时，批量操作条固定在可视区底部，不被手机导航遮挡；关闭选择或完成操作后移除。

## 经营概览

- 页面首屏突出 API 返回的累计/当前范围利润；不制造同比、环比或预测数据。
- 销售额、总成本、ROI 和成交笔数以紧凑 2×2 账本块显示；保留数据不完整提示。
- 月度利润图保留原有正负基线和真实月份数据，允许横向滚动，不能为适配窄屏压缩到不可读。
- 页面仍通过侧边栏返回交易与进入分析。

## 利润分析

- 保留现有月份控制、月度趋势、利润区间、状态分布、退货摘要及交易下钻链接。
- 月份控制保证至少 44px 触控高度；趋势图与概览图相同，横向滚动优先于压缩。
- 三类统计继续使用可展开账本项；展开后产品链接跳转交易页并触发既有聚焦行为。
- 分析页面不得添加新的分组、利润占比或后端未提供的数据。

## 自用中、在售中、设置与状态

- 自用中和在售中仍为单独路由和列表，沿用交易行的移动阅读密度；保留搜索、排序、添加、编辑、“标记在售”和“确认售出”等当前动作。
- 设置保持现有只读信息范围，置于侧边栏入口中。
- 所有加载、错误、空状态、确认弹窗、通知和 React Query 失效逻辑维持原有行为。抽屉、筛选面板和交易编辑不能相互遮挡且必须正确管理焦点。

## 视觉与可访问性

- 沿用既有冷静、低饱和、细边框的设计系统与浅色/深色变量；不添加渐变、玻璃拟态或无业务价值的装饰卡片。
- 手机页面边距为 16px 左右，顶部栏高度约 52–56px；所有主要触控元素至少 44×44px。
- 使用现有 Lucide 图标；状态同时保留文字；保留键盘焦点样式和 `prefers-reduced-motion` 降级。
- 覆盖式侧边栏和移动表单使用浮层阴影，其他页面层级优先由留白、边框和排版表达。

## 代码边界

- `AppShell` 负责手机顶部栏、侧边抽屉、账号/主题/语言操作以及桌面与手机壳的切换。
- 新增的移动导航、筛选溢出和工具栏组件应职责单一，页面组件继续负责现有查询、突变和路由状态。
- `TransactionsPage`、`SelfUsePage`、`OverviewPage`、`AnalyticsPage` 只调整自身的移动结构和可访问的操作入口；领域层、API 客户端和数据格式不改变。
- 样式继续集中在现有 CSS 自定义属性和响应式规则中，不引入 UI 框架。

## 验证标准

1. 所有现有单元/组件测试通过，并补充手机菜单开关、导航、可访问操作入口及移动布局相关测试。
2. `typecheck`、`lint`、`test` 和 `build` 通过。
3. 在 390×844 与 360×800 视口逐页验证浅色、深色和减少动画：交易、概览、分析、自用中、在售中、设置、编辑表单、筛选和确认弹窗。
4. 验证登录后的默认入口仍是交易明细；侧边栏可以到达全部桌面业务页；交易 CRUD、导出、筛选、批量操作、销售确认、主题/语言切换及分析下钻可用。
