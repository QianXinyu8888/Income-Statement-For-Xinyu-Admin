# 闲鱼交易明细及损益管理系统 - 重构与新功能设计规格说明书

- **日期**: 2026-08-05
- **状态**: 草案 (待用户最终审核)
- **主题**: 视觉重构、当月看板、损益区间分布、带公式 Excel 导出与极速记账升级

---

## 1. 目标与背景

本项目为闲鱼卖家打造高阶交易与损益控制台。针对用户提出的 **“极速记账 (A)”、“飞书/Excel双向同步 (D)”、“当月看板”、“损益区间分布”与“带公式高级 Excel 导出”** 需求，本规范定义了完整的架构设计、数据流与组件交互细节。

---

## 2. 核心功能设计规格

### 2.1 📅 当月看板 (Current Month Dashboard)

- **月度切片过滤器**:
  - 在仪表盘顶部提供月份选择器（如 `2026年8月`、`2026年7月` 或 `自定义月份`），默认选择当前系统月份。
- **当月 5 大核心 KPI**:
  - **当月成交流水**: 仅统计选定月份的成交总额。
  - **当月实际净利润**: 选定月份的实际到手收益（带同比/环比微型增长指示器）。
  - **当月成交笔数**: 选定月份已完成交易笔数。
  - **当月运费支出**: 选定月份消耗的快递运费。
  - **当月平均 ROI**: 选定月份卖出商品的平均投资回报率。
- **当月 vs 历史对比图**:
  - 柱状/折线对比选定月份与前几个月的盈亏走势。

### 2.2 📊 损益区间分布 (Profit Bracket Breakdown)

- **区间划分逻辑**:
  - 🚀 **高收益单品** (`利润 > ¥500`)：绿色亮光 Badge，计算其占总利润的比重。
  - 📈 **稳健盈利** (`¥100 <= 利润 <= ¥500`)：蓝绿色 Badge。
  - ⚖️ **平价回血** (`¥0 <= 利润 < ¥100`)：蓝色 Badge。
  - 🔻 **亏损单品** (`利润 < ¥0`)：红色警示 Badge。
  - 📦 **自用单品** (`交易状态包含'自用'`)：紫灰色 Badge。
- **可视化呈现**:
  - 仪表盘与分析页增加分段色彩分布条（Progress Segment Bar）与分类列表。

### 2.3 📊 带公式的高级 Excel 导出 (Advanced Excel Export with Formulas)

- **Excel 公式映射**:
  - 导出的 `.xlsx` 文件不仅包含纯文本数据，还在特定列中直接写入原生 Excel 公式：
    - `F列 (实际净利润)`: `=C2-D2-E2` (成交价 - 购入成本 - 运费)
    - `G列 (ROI)`: `=IF(D2>0, F2/D2, 0)`
  - 导出表头包含格式化货币样式与表格自动列宽适配。

### 2.4 ⚡ 极速记账与表格内直编 (Quick Add & Inline Status Toggle)

- **文本智能粘贴解析 (Smart Paste Parser)**:
  - 新增 Modal 中增加“一键粘贴解析”输入框，支持粘贴闲鱼复制的商品描述、淘口令或买家留言，自动正则提取 `商品名称` 与 `价格`。
- **大表 1 秒内联切换状态 (Inline Status Toggle)**:
  - 交易大表中的状态标签升级为内联快捷 Dropdown/Pill，在表格中点击一次即可将状态由 `自用中` 切换为 `已售出` 或 `已退货`，自动同步飞书。

## 3. UI 视觉设计标准 (Apple Spatial Glass)

- **设计语言**: 苹果 iOS 18 磨砂玻璃 (`backdrop-blur-xl`) + 1px 动态 Glow 边框。
- **数字排版**: 金融级等宽字体 (`font-tabular-nums`)。
- **主题模式**: 完美支持跟随 OS 系统主题、深色模式与浅色模式。
