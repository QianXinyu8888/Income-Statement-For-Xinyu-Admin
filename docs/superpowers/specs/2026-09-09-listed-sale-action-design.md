# 在售中页面售出操作设计

## 目标

把“在售中”页面每行的状态下拉菜单替换为直接可见的售出操作，让用户不必先打开“设为状态”菜单即可开始售出流程。

## 交互

- “在售中”页面每行操作区显示 `设为` 文字及 `已售出` 按钮。
- 点击 `已售出` 打开现有“确认售出”窗口；此时尚不修改记录状态。
- 用户在窗口中填写必填的售价和售出日期，可选填写备注；点击“确认售出”后，系统将记录更新为“已售出”。
- 保存期间，操作按钮和窗口表单沿用现有禁用状态，避免重复提交；保存失败时保留窗口输入和错误反馈。
- “自用中”页面不在本次变更范围内，继续使用现有的状态选择菜单。

## 实现边界

- 只调整 `SelfUseList` 的在售中行操作呈现与对应测试、样式。
- 复用既有 `SaleConfirmDialog`、售出数据校验及更新接口，不改动 API、飞书字段或交易计算规则。
- 桌面表格与移动列表均显示同样的 `设为 + 已售出` 操作。

## 验收

1. 在售中页面不再显示“设为状态”下拉框。
2. 每个在售物品均有“设为 已售出”操作。
3. 点击按钮后出现售价、售出日期和备注输入窗口，确认后记录成为“已售出”。
4. 自用中页面原有操作保持不变。
