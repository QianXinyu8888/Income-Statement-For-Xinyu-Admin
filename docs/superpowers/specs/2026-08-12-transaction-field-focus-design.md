# 交易字段点击定位设计

## 目标

交易列表中的可编辑字段成为编辑入口。用户点击某个字段后，打开该交易的现有编辑抽屉，并把键盘焦点定位到对应表单控件。新增交易继续默认聚焦商品名称。

## 交互范围

- 支持点击定位：商品名称、交易状态、购入日期、售出日期、购入成本、运费、成交价、备注。
- 保持只读：持有天数、总成本、利润；点击这些内容不打开编辑抽屉。
- 桌面表格与移动卡片使用同一字段映射。
- 字段入口使用原生按钮，支持鼠标、触屏、Tab 与 Enter/Space 操作，并提供可识别的悬停和焦点样式。
- 打开编辑抽屉后保留原值；文本输入与文本域的插入光标落在内容末尾，不自动全选。
- 点击“新增交易”时没有来源字段，仍聚焦商品名称。

## 组件与数据流

- `TransactionList` 定义可编辑字段键，并通过 `onOpen(record, field)` 把来源字段传给页面。
- `TransactionsPage` 保存当前编辑记录与目标字段，在打开抽屉时同步更新；新增交易使用默认的商品名称目标。
- `TransactionDrawer` 接收目标字段，通过稳定的 ref 映射在抽屉打开且表单数据完成填充后聚焦对应控件。
- 不修改交易模型、API、飞书映射、保存逻辑或 URL。

## 焦点与可访问性

- 表单控件沿用现有可访问名称。
- 抽屉的焦点陷阱、Escape 关闭、嵌套确认框优先级和关闭后恢复触发元素的逻辑保持不变。
- 字段目标无效或控件不可用时安全回退到商品名称。

## 测试

- 列表测试验证每个可编辑字段会携带正确字段键打开交易，并验证只读字段不是按钮。
- 抽屉测试验证指定字段获得焦点、文本光标在末尾、新增交易默认聚焦商品名称。
- 页面测试验证列表来源字段正确传递到抽屉。
- 完整运行测试、类型检查、lint、格式检查和生产构建。
