# 主题化加载 SVG 设计

## 背景

当前加载资源 `public/loading.gif` 是白底黑点 GIF，在暗色主题下会显示为明显的白色方块，无法继承页面主题色。

## 方案

采用 E「双轨核心」作为统一加载动画：两条半透明椭圆轨道围绕中心圆点旋转。动画以 inline SVG 实现，使用 `currentColor` 继承 `--accent`，因此浅色和暗色主题都能保持一致的视觉语义。

## 约束

- 动画尺寸保持 32×32px。
- 动画周期约 1.2 秒，连续循环且不过度跳跃。
- 不增加运行时依赖，不保留 GIF 加载引用。
- `LoadingState` 继续提供 `role="status"` 和可见加载文案。
- 设置页账户角色同步状态使用同一加载组件。
- 另存一份可独立复用的 SVG 到桌面。

## 验证

- 更新 LoadingState 与 SettingsPage 测试，断言 SVG 存在且 GIF 引用不存在。
- 运行相关单元测试、类型检查和构建。
- 在浏览器中分别检查浅色和暗色主题，确认无白色背景块。
