# 空值兼容、财务口径与删除交互设计

## 目标

在不修改飞书字段和历史数据的前提下，让项目完整展示飞书交易记录，禁止为缺失数据设置默认值或推导值；同时修正未成交利润、退货统计、总成本展示、完整导出和删除确认交互。

## 不可违反的数据原则

- 飞书字段为空时，API 保持 `null`，界面统一显示 `—`。
- 不把空售价、购入成本或运费转换为 `0`。
- 不推测商品名称、交易状态、购入日期或售出日期。
- 飞书公式字段“总成本(¥)”“利润(¥)”“ROI”“持有天数”为空时，不在 API 层补算。
- 表单可根据用户当前输入显示明确标注的预计值，但预计值不写入飞书公式字段，也不作为持久化结果返回。
- 新增和完整编辑时仅要求商品名称与交易状态；其他业务字段允许暂时为空。

## 数据模型

读取模型 `Transaction` 中除记录 ID 外的飞书业务字段均可为空。金额和公式字段使用 `number | null`，日期使用 `string | null`，状态使用 `TransactionStatus | null`，文本字段使用 `string | null`。

写入模型单独定义：商品名称与交易状态必填；成交价、购入成本、运费、购入日期、售出日期、排序和备注可为空。写入飞书时只发送普通可写字段，不发送公式字段。

项目读取的“总成本”只来自飞书 `总成本(¥)` 公式。当前公式语义为：购入成本为空则总成本为空，否则总成本为购入成本与运费之和。

## 展示规则

- 交易主列表默认列为商品、状态、售价、总成本、利润、售出日期。
- 主列表不同时展示购入成本和总成本，避免重复信息。
- 新增和编辑抽屉展示购入成本、运费与只读的预计总成本；保存后以飞书公式结果为准。
- 详情和导出保留购入成本、运费、总成本三项。
- 飞书缺失值、业务不适用值和未成交利润统一显示 `—`，不显示虚假亏损。
- 在售中、自用中和缺少实际利润公式结果的记录不显示利润数值。

## 经营统计口径

普通经营指标只统计状态为“已售出”的记录：

- 成交笔数按真实“已售出”状态计数，不要求金额完整。
- 销售额只累加真实存在的成交价。
- 总成本只累加真实存在的飞书总成本公式值。
- 利润只累加真实存在的飞书利润公式值。
- ROI 使用 `利润 / 总成本`；总成本为空或不大于零时为空。
- 月度趋势仅使用真实售出日期；缺少售出日期的记录不分配到任何月份。
- 利润区间仅使用真实利润值。

“已退货”不进入销售额、普通总成本、利润、ROI、成交笔数、月度趋势和利润区间。分析结果单独返回退货笔数与退货损失。退货损失只使用飞书利润公式中真实存在的负值，转换为正数展示；没有利润值时不推导运费损失。

API 返回 `incompleteCount`，表示至少一个经营统计所需字段为空的已售出记录数量，避免用户把已知金额汇总误认为完整总额。

## 全量导出

新增受鉴权保护的 `GET /api/v1/transactions/export`。该接口读取飞书全部记录，执行与列表相同的无推导映射，但不接收搜索、状态、日期、排序或分页参数。

前端点击 CSV 或 Excel 时先请求该接口，再生成文件。导出包含全部记录，包括字段不完整和已退货记录，字段顺序为商品名称、交易状态、购入日期、售出日期、成交价、购入成本、运费、总成本、利润、ROI、持有天数、排序、备注。空值输出为空单元格，文本继续执行电子表格公式注入防护。

导出过程中按钮显示进行中并禁止重复点击；失败时显示统一错误通知，不生成部分文件。

## 删除确认框

采用用户选择的方案 A：桌面与手机均使用居中的应用内确认对话框。

- 单条删除显示商品名称和“删除后无法恢复”。
- 批量删除显示明确的选中数量。
- 默认焦点位于“取消”，危险按钮使用红色且文案为“删除”。
- 打开后锁定焦点，`Escape` 取消，点击遮罩取消。
- 关闭后焦点返回触发删除的按钮。
- 确认后才调用删除 API；请求进行中禁用按钮。
- 删除失败时关闭或保留对话框均不得清空当前选择，界面显示错误。

## API 与错误处理

- 列表 API 不再捕获映射错误后删除整条记录；缺失字段正常映射为 `null`。
- 只有字段值类型无法解析或状态值不属于飞书真实选项时才返回映射警告；对应记录仍以可展示的原始空值模型返回，不得伪造默认状态。
- 前端显示数据警告数量，但不把警告记录从总数中扣除。
- 所有写操作继续等待飞书业务成功后再更新界面。

## 测试与验收

- 映射测试覆盖空金额、空日期、空状态、空公式字段，断言不会变成 `0`、当前日期、默认状态或推导值。
- 列表组件测试覆盖空值显示 `—`、未售出利润显示 `—`、主列显示总成本。
- 统计测试覆盖已售出、在售中、自用中、已退货和不完整记录，断言退货不进入普通利润并单列损失。
- 导出测试覆盖全量接口不接受筛选、全部记录数量、空单元格、字段顺序和公式注入防护。
- 删除对话框组件测试覆盖默认焦点、Tab 循环、Escape、取消、确认、焦点恢复和请求中状态。
- 浏览器验收覆盖桌面与 360px 手机：列表、详情、全量 CSV/Excel、单删、批量删除和失败恢复。
- 最终运行类型检查、Lint、单元/组件测试和生产构建。

## 范围边界

本次不修改飞书公式、不回填历史空字段、不新增分类字段、不引入数据库，也不改变现有 Cloudflare 部署架构。
