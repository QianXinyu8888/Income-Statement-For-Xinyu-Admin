# 网页端浏览器偏好设计

## 背景与目标

当前设置页展示账号、服务状态和缩减动画偏好；主题只能通过顶部栏在浅色与深色之间切换。交易明细始终显示全部字段，利润分析使用起止日期筛选且不会记住用户选择。

本次改造面向网页端管理后台，目标是减少高频重复操作，同时将页面级配置留在其使用场景内：

- 交易明细页支持控制字段显示。
- 主题支持跟随系统。
- 利润分析页支持按年月选择分析周期。
- 所有新增偏好仅保存在当前浏览器，不进行账号级或跨设备同步。

## 范围

### 交易字段显示

- 在交易明细页工具栏增加“列”按钮，不在设置页重复提供入口。
- 点击按钮打开字段开关面板；桌面端使用锚定弹层，手机浏览器使用适配窄屏的底部面板。
- 面板列出 11 个业务字段：商品名称、交易状态、购入日期、售出日期、持有天数、购入成本、运费、总成本、成交价、利润、备注。
- 商品名称始终显示且不可关闭；其余 10 个字段可自由显示或隐藏。
- 选择框列始终保留，不属于可配置业务字段。
- 默认显示全部业务字段。“恢复默认”将 11 个字段恢复为全部显示。
- 字段开关即时生效，桌面表格和手机卡片共用同一份可见性配置。
- 本期不支持字段拖拽排序，也不改变既有字段顺序。

### 主题模式

- 设置页的外观区域提供“跟随系统 / 浅色 / 深色”三态选择。
- 没有历史主题偏好的新浏览器默认跟随系统。
- 已经保存浅色或深色偏好的浏览器继续使用原有明确主题，不强制迁移到跟随系统。
- 跟随系统模式监听 `prefers-color-scheme` 的变化并实时更新页面。
- 顶部栏保留现有主题快捷按钮。点击后根据当前实际主题切换为明确的相反主题：当前实际为深色时保存浅色，当前实际为浅色时保存深色。
- 用户可在设置页重新选择跟随系统。
- 现有缩减动画偏好继续保留，不纳入本次功能扩展。

### 分析月份

- 利润分析页以年月选择器替代现有起止日期输入，使用 `YYYY-MM` 作为页面偏好值。
- 第一次访问或保存值无效时默认本月。
- 用户选择年月后立即查询该自然月的数据，并将选择保存在当前浏览器。
- 页面刷新或重新进入时恢复最后一次有效选择。
- 提供“重置为本月”按钮；点击后立即选择本月、保存偏好并重新查询。
- 查询沿用现有分析接口。前端按本地日期计算所选月份第一天和最后一天，转换为接口需要的起止日期。
- 支持任意有效年月；未来月份允许选择，接口没有数据时沿用现有空状态。

## 不在范围内

- 账号级偏好、跨浏览器或跨设备同步。
- 字段顺序调整、列宽拖拽和多套表格预设。
- 默认筛选条件、默认排序、分页数量或默认进入页面。
- 字号、币种、时区、语言、通知、离线模式和自动后台刷新。
- 后端接口、飞书数据结构或权限模型变更。

## 组件与职责

### 浏览器偏好层

新增统一的浏览器偏好模块，包含纯存储函数和 React Provider：

- `readPreferences`：读取、解析、校验并补齐默认值。
- `writePreferences`：序列化当前有效偏好；写入失败时不抛出到界面。
- `BrowserPreferencesProvider`：持有当前偏好并暴露有类型的更新方法。
- 消费组件不直接解析 `localStorage`，避免不同页面产生不一致的默认值和迁移逻辑。

建议使用一个带版本号的命名空间对象：

```ts
interface BrowserPreferencesV1 {
  version: 1;
  themeMode: 'system' | 'light' | 'dark';
  visibleTransactionFields: TransactionFieldId[];
  analysisMonth: string;
  reduceMotion: boolean;
}
```

`analysisMonth` 允许为空字符串表示尚未选择，读取后由当月默认值补齐。`visibleTransactionFields` 读取时过滤未知字段并强制加入商品名称。旧的 `theme` 和 `reduce-motion` 键在首次读取时迁移到统一对象；迁移成功后可以保留旧键以避免破坏未同步更新的页面代码，待全部消费者切换后再单独清理。

### `ColumnVisibilityPanel`

- 接收完整字段定义、当前可见字段集合、更新回调和恢复默认回调。
- 只负责展示与交互，不负责读取浏览器存储。
- 商品名称开关呈禁用和锁定状态，明确说明它不可隐藏。
- 桌面弹层锚定“列”按钮；窄屏使用相同语义内容的底部面板。
- 支持点击外部、关闭按钮和 `Esc` 关闭。

### `TransactionList`

- 新增可见字段集合参数。
- 桌面表头和对应单元格使用同一字段定义进行条件渲染，避免表头与数据错位。
- 手机卡片按相同字段 ID 决定各信息块是否渲染，但保持手机专属布局。
- 隐藏字段不会保留空单元格或空白详情项。

### `ThemePreferenceControl`

- 展示三个互斥选项并更新 `themeMode`。
- Provider 根据模式计算实际主题，并负责更新文档根节点。
- 仅在 `themeMode === 'system'` 时订阅系统主题变化；明确主题不受系统变化影响。
- 如果浏览器不支持系统主题查询，跟随系统回退为浅色。

### `AnalysisMonthControl`

- 展示原生年月输入和“重置为本月”按钮。
- 校验 `YYYY-MM`，计算本地自然月的起止日期。
- 更新选择时同步更新偏好和现有分析查询参数。
- 日期边界计算必须正确处理 28、29、30、31 天月份。

## 交互与数据流

### 字段显示

1. 用户打开“列”面板。
2. 用户切换某个可配置字段。
3. Provider 更新可见字段集合并尝试写入浏览器存储。
4. 桌面表格与手机卡片收到同一份新配置并即时重新渲染。
5. 用户点击“恢复默认”后，所有 11 个业务字段恢复显示。

### 主题

1. Provider 读取 `themeMode`。
2. 明确主题直接成为实际主题；系统主题通过媒体查询解析。
3. 实际主题写入文档根节点，驱动现有 CSS 自定义属性。
4. 顶部栏快捷按钮把当前实际主题切换为明确的相反主题。
5. 设置页三态控件始终显示当前保存的模式，而不是只显示计算后的实际主题。

### 分析月份

1. 页面读取保存的有效年月；没有有效值时使用本月。
2. 前端计算该月第一天和最后一天。
3. 现有分析查询使用两个日期请求汇总数据。
4. 用户更改年月或重置后立即重复上述流程。

## 响应式与溢出处理

- 桌面表格移除隐藏字段对应的表头和单元格，继续保留现有横向滚动作为极端宽度兜底。
- 手机卡片在字段隐藏后重新排列剩余详情项，不留下空白占位。
- 商品名称始终位于手机卡片顶部，长文本允许换行并使用 `overflow-wrap` 防止撑破容器。
- 备注允许多行换行；金额和日期采用不会撑破网格的最小宽度与换行策略。
- 手机详情网格必须正确处理奇数个可见字段；最后一项不产生不必要的整行空白。
- 至少验证 320px、680px 和常规桌面宽度；浅色与深色主题均需验证。
- 列面板在窄屏不得超出视口，内容过长时仅面板内部滚动。

## 可访问性

- “列”按钮提供可访问名称、`aria-expanded` 和与面板的关联。
- 面板打开后焦点进入面板，关闭后返回触发按钮。
- 所有字段开关具有明确标签；商品名称的禁用状态可以被辅助技术识别。
- 键盘用户可遍历所有控件并使用 `Esc` 关闭面板。
- 主题三态控件使用单选语义或等价的可访问分段控件。
- 年月输入具有可见标签；重置按钮名称明确说明目标是本月。

## 错误处理与降级

- 浏览器存储缺失、JSON 损坏、版本未知或字段值非法时，读取逻辑返回安全默认值。
- 浏览器禁止或拒绝存储写入时，界面状态在当前会话继续生效，不弹出阻断操作的错误框。
- 可见字段配置为空或只包含未知字段时，强制恢复商品名称；“恢复默认”始终可用。
- 无效分析月份回退本月；有效未来月份没有数据时显示现有空状态。
- 系统主题查询不可用时，跟随系统使用浅色，不影响手动选择浅色或深色。

## 测试与验收

### 单元测试

- 默认偏好、旧主题和缩减动画迁移。
- 损坏 JSON、未知版本、未知字段和存储异常回退。
- 商品名称强制可见以及恢复全部默认字段。
- 年月格式校验和自然月边界，包括闰年二月。
- 三态主题到实际主题的计算。

### 组件测试

- “列”按钮打开和关闭面板，`Esc` 与点击外部关闭有效。
- 商品名称不可关闭，其余 10 个字段均可切换。
- 桌面表头与数据单元格同步隐藏，不发生列错位。
- 手机卡片按同一配置隐藏对应详情项，编辑入口仍指向正确字段。
- 跟随系统响应媒体查询变化；明确主题不响应系统变化。
- 顶部主题按钮从实际主题切换到明确的相反主题。
- 分析页默认本月、恢复保存年月、选择年月和重置本月。

### 回归与视觉验收

- 保留交易编辑、选择、批量操作、分页、焦点定位和分析下钻行为。
- 使用空值、超长商品名称、超长备注、大额金额和负利润数据验证布局。
- 在 320px、680px 和桌面宽度验证无页面级横向溢出、控件遮挡或不可操作内容。
- 在浅色、深色和跟随系统两种实际主题下验证对比度和状态一致性。

## 完成标准

- 三项功能均按上述页面位置和交互工作。
- 新增偏好只保存在当前浏览器，刷新后保持，不跨设备同步。
- 默认体验保持兼容：交易字段全部显示，既有明确主题继续使用，分析默认本月。
- 自动化测试通过，桌面与手机浏览器布局没有字段错位、文本溢出或操作回归。
