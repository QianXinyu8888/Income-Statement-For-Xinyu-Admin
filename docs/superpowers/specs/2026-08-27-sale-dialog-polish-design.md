# 售出确认窗口微调设计

## 目标

让售出确认窗口的售价输入栏在聚焦时保持清晰、稳定的 macOS 表单观感，并将自用天数提示改为紧凑、自然的中文句式。

## 范围

- 价格输入框中的 `¥` 作为不可编辑的左侧前缀，与数字输入区域明确分隔。
- 聚焦时只由外层价格控件呈现蓝色焦点环；内部输入框不再产生叠加边框或轮廓。
- 提示文案使用“今天是你自用{物品名}的第 {天数} 天”，物品名称两侧不插入空格。

## 实现

- 只调整 `SaleConfirmDialog` 的提示文本和 `styles.css` 中售价控件的布局与焦点样式。
- 保留现有金额校验、键盘聚焦、辅助功能标签和售出数据提交逻辑。
- 为提示文案补充组件测试，确认名称紧贴“自用”和“的第”。

## 验收

- 聚焦售价输入框时，`¥` 靠左稳定显示，数字输入从其右侧留白处开始。
- 输入框只显示一层连续的蓝色焦点描边。
- `迈金C606` 的提示为“今天是你自用迈金C606的第 13 天”。
