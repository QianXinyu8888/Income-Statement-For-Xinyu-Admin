# 产品状态回退与可选售出信息设计

## 目标

让“在售中”物品可以直接切回“自用中”，并允许用户在标记“已售出”时不填写售价、售出日期或备注。

## 直接状态操作

- “自用中”页面每行保持 `设为 + 在售中 + 已售出`。
- “在售中”页面每行改为 `设为 + 自用中 + 已售出`。
- 点击“在售中”或“自用中”均立即调用既有单项状态更新接口；成功后刷新相关列表和统计，失败时显示接口错误并维持原状态。
- 点击“已售出”继续打开售出确认窗口，不会在打开窗口时提前变更状态。

## 售出确认窗口

- 售价、售出日期和备注均为可选字段；移除必填标记和空值拦截。
- 每次打开窗口时，售价与售出日期初始化为空，备注沿用当前记录备注。
- 确认时，空售价写入 `null`，空售出日期写入 `null`，空备注写入 `null`；不得写入 `0`、当天日期或空字符串。
- 填写的售价仍必须是大于等于 0 的有效金额；非空售出日期继续受浏览器日期输入和领域 schema 校验。
- 售价为空时利润预览显示“—”。

## 数据与测试边界

- 将售出表单值的售价和售出日期类型扩展为可空值，并让 `createSaleInput` 直接写入这些空值。
- 不修改交易 API、飞书字段映射或财务统计规则；已售出但缺少价格/日期的记录仍按既有空值规则显示。
- 覆盖两种状态页面的直接回退/前进操作、空售出信息提交、无效非空售价的阻止，以及现有完整售出信息的提交。
